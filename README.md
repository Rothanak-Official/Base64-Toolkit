🔐 Base64 Toolkit

Base64 Toolkit is an Android utility application designed for working with Base64 encoding and decoding in a simple, fast, and user-friendly interface.

«🧪 Version: v1.0 (BETA)
📱 Platform: Android
🚧 Status: Beta»

✨ Features

- 🔤 Base64 Encode
- 🔓 Base64 Decode
- 📋 Easy copy and paste
- 📝 Input / Output text fields
- ⚡ Fast Base64 processing
- 🎨 Custom color / accent color
- 🖱️ Custom text insertion cursor color
- 🎨 Color Picker
- 🔢 HEX color support
- 🔴 RGBA color values
- 📱 Android-friendly interface
- 💾 Simple and lightweight

📲 Installation

1. Download "Base64 Toolkit v1.0 (BETA).apk" from the Releases page.
2. Open the APK on your Android device.
3. If Android asks for permission, allow installation from unknown sources for your browser/file manager.
4. Install the application.
5. Open Base64 Toolkit.

«⚠️ Only install APK files downloaded from a source you trust.»
